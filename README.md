# Space Game

Небольшой pygame-проект про космическую сцену с меню, фоном, метеорами,
кораблём игрока, боссом и голосовым диалогом.

## Запуск

```powershell
py -3.12 -m pip install -r requirements.txt
py -3.12 main.py
```

Проект проверен с Python 3.12. В текущем окружении Python 3.14 не подходит:
`pygame` для него пытается собираться из исходников и падает на Windows-сборке.

## Текущая структура

- `main.py` - короткая точка входа.
- `space_game/app.py` - главный игровой цикл и переключение сцен.
- `space_game/scenes/` - сцены `intro`, `menu`, `act_one`, `ending`.
- `space_game/entities/` - игровые объекты: игрок, босс, метеоры, фон.
- `space_game/audio/` - музыка и голосовой диалог.
- `space_game/ui/` - UI-компоненты pygame, сейчас слайдер громкости.
- `space_game/data/` - статические данные, например порядок реплик диалога.
- `assets/` - изображения и музыка.
- `docs/` - заметки по ревью и дальнейшей архитектуре.

Старые каталоги `models/` и `managers/` оставлены для сравнения во время
перехода. Новую разработку лучше вести в пакете `space_game`.
